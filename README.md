Vice Coast Cover Studio: an offline web app that turns any photo and a caption into GTA 6-style multi-panel cover art — bold poster lettering, Vice City sunset and neon grades — and exports it as a PNG in post sizes (1080x1080, 1080x1350, 1920x1080).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. The app works offline; photos never leave the machine. To hand the app in, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.
